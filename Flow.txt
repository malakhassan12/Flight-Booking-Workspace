Seat Service
*************
| #  | API / Command                  | Type          | Input                                          | Output / Purpose                               | Used By                |
| -- | ------------------------------ | ------------- | ---------------------------------------------- | ---------------------------------------------- | ---------------------- |
| 1  | `GET /flights/:flightId/seats` | Query         | `flightId`                                     | كل المقاعد + `seatNumber` + `class` + `status` | API Gateway / Frontend |
| 2  | `seat.checkAvailability`       | Query         | `flightId`, `seatId`                           | `{ available: true/false }`                    | Booking Service        |
| 3  | `seat.getStatus`               | Query         | `flightId`, `seatId`                           | Seat status                                    | Booking / API Gateway  |
| 4  | `seat.getAvailable`            | Query         | `flightId`                                     | `{ availableSeats: 42 }`                       | Flight/Search          |
| 5  | `seat.lock` ⭐                  | Command       | `flightId`, `seatId`, `bookingId`, `expiresIn` | `LOCKED` + `lockId` + `expiresAt`              | **Booking Service**    |
| 6  | `seat.confirm` ⭐               | Command       | `flightId`, `seatId`, `bookingId`, `lockId`    | `BOOKED`                                       | **Booking Service**    |
| 7  | `seat.release` ⭐               | Command       | `flightId`, `seatId`, `bookingId`, `lockId`    | `AVAILABLE`                                    | **Booking Service**    |
| 8  | `seat.releaseAll` ⭐            | Command       | `bookingId`                                    | Release all seats belonging to booking         | **Booking Service**    |
| 9  | `seat.getBookingSeats`         | Query         | `bookingId`                                    | All seats belonging to booking                 | Booking Service        |
| 10 | `seat.getFlightSeatStats`      | Query         | `flightId`                                     | Total / available / locked / booked counts     | Flight/Search/Admin    |
| 13 | `seat.disable`                 | Command/Admin | `seatId`, reason                               | Seat becomes unavailable                       | Admin                  |
| 14 | `seat.enable`                  | Command/Admin | `seatId`                                       | Seat becomes available again                   | Admin                  |
